# BongDa.com V2
Virtual-points football and game portal demo.

Run locally: npm install && npm start
Open: http://localhost:3000
Admin: admin@demo.local / Admin123!

For Internet deployment, this app listens on process.env.PORT and can be deployed to a Node.js host such as Render. SQLite is suitable for a demo but should be replaced by a persistent managed database for production.
